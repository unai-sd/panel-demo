# panel-demo

Admin dashboard for **Demo Fitness** (fictitious gym chain): member overview, membership plans and a
pricing calculator that applies the current discount rules.

| Package         | Purpose                                        |
| --------------- | ---------------------------------------------- |
| `apps/web`      | React + Vite admin app                         |
| `packages/core` | Membership plans, pricing rules, member status |
| `packages/ui`   | Shared React components                        |

## Getting started

```sh
corepack enable
pnpm install
pnpm dev
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.
